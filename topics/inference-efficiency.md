## Server-Side Dominance for Agentic Workloads

**Primary driver**: Increasingly high memory demands for agents, particularly KV cache requirements, make server-side inference economically favorable for agentic workloads. 

**Key architectural trend**: Thin client approach taken to extreme—users don't need local compute even for real work accomplishment. The AI on the server does it all, with the device serving purely as an interaction portal.

### Portal Devices and Project Solara

Microsoft's Project Solara (announced Build 2026) envisions an ecosystem where devices function as "portals" to interact with cloud-resident agents rather than standalone computing platforms. This extends the thin client concept beyond simple inference queries to full autonomous task execution.

**Rationale beyond KV cache**: Agents decouple interaction time from computation time. Brief interactions (seconds) can trigger extended autonomous work (hours), making local compute less critical than in traditional paradigms where computing equals interacting.
