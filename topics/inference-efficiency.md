## Server-Side Inference Dominance for Agent Workloads

**KV cache memory demands drive centralization**: Agent workloads characterized by increasingly high memory demands, particularly for KV cache storage. This creates strong economic incentive for [[server-side-inference]] over local compute for [[agentic-workflows-production]].

**Thin client computing for agents**: Agent computing extends thin client concept to "absolute extreme"—users don't need local compute even to accomplish real work, only to make requests and receive results. All agent execution happens server-side. (See [[ai-native-product-design]] for interaction paradigm implications)

**Interaction time decoupling**: Agents decouple computation time from interaction time. Brief interaction (seconds) can trigger extended server-side work (hours), making thin client approach particularly compelling beyond traditional inference latency considerations.
