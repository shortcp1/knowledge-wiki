# Model Architecture

## Encoder-Free Multimodal Architectures

### Gemma 4 12B (Google DeepMind, June 2026)
- **Architecture**: Unified encoder-free multimodal model at 12B parameters
- **Design**: Single unified architecture processing multiple modalities without dedicated encoders
- **Significance**: Part of broader industry trend toward [[encoder-free-fusion]] approaches
- **Trade-off**: Encoder-free designs reduce architectural complexity and likely improve [[inference-efficiency]] but may sacrifice some modality-specific optimization
