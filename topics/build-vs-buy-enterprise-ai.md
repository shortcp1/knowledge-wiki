## Model Selection Criteria Evolution

### Traditional Enterprise AI Procurement (pre-2026)

**Standard RFP evaluation dimensions**:
- Price (input/output token costs)
- Latency
- Context window size
- Benchmark scores (accuracy, reasoning, coding)

### Emerging Selection Criteria: Model Worldview (2026+)

**Source**: Tomasz Tunguz, July 2026

**Context**: The Economist's World Values Survey evaluation of 25 frontier models revealed significant worldview variance across models from different labs and within same-lab model families.

**Use case dependency**:

**Worldview-irrelevant applications**:
- Code generation
- SQL queries
- Log parsing  
- Image classification
- Technical computation tasks

**Worldview-sensitive applications** (where model values affect business outcomes):
- Marketing copy generation (must match target demographic values)
- Customer behavior predictions
- Customer support tone/responses
- Business analysis and forecasts
- Hiring decision support
- Policy analysis and recommendations

**Procurement implication**: For value-sensitive use cases, enterprises may need to evaluate model alignment with target market demographics and corporate values as part of selection process.

**Status (2026)**: Model worldview not yet standard consideration in enterprise AI procurement, but emerging as factor for specific deployment contexts.

See also: [[post-training-rlhf]] for technical mechanisms behind worldview differences.
